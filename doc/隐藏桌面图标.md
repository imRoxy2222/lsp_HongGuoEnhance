# 隐藏桌面图标

## 功能

设置页"应用"分组提供 **隐藏桌面图标** 开关。开启后模块从桌面
（Launcher）消失，作为 LSPosed 模块不再暴露入口；需要修改配置时在
**LSPosed 管理器**的模块页面打开本模块即可。

## 实现原理

### activity-alias 承载入口

LAUNCHER intent-filter 从 `MainActivity` 迁移到别名组件
`.LauncherAlias`（`AndroidManifest.xml`），`MainActivity` 本体改为
`exported="false"`：

```xml
<activity-alias
    android:name=".LauncherAlias"
    android:enabled="true"
    android:exported="true"
    android:targetActivity=".MainActivity">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>
</activity-alias>
```

隐藏 = 通过 `PackageManager.setComponentEnabledSetting` 把别名置为
`COMPONENT_ENABLED_STATE_DISABLED`；恢复 = 置回 `ENABLED`。
操作使用 `DONT_KILL_APP` 标志，不中断当前进程。

- 状态由系统（packages.xml）持久化，重启 / 覆盖安装后保持，无需额外存储；
- 隐藏只影响桌面入口，LSPosed 加载 hook 不受影响；
- 隐藏后从 LSPosed 管理器的模块页面仍可打开设置页（`MainActivity`
  本体保持启用，不受别名禁用影响）。

### LSPosed 管理器"启动"按钮的保活（重要）

LSPosed 管理器决定是否显示"启动"按钮的逻辑见其
`AppHelper.getSettingsIntent()`：

1. 优先查询带 `de.robv.android.xposed.category.MODULE_SETTINGS`
   类别（Xposed 模块设置页标准类别）的组件；
2. 否则回退到 `getLaunchIntentForPackage`：先查
   `CATEGORY_INFO`，再查 `CATEGORY_LAUNCHER`。

若三者都解析不到，按钮直接消失。而本模块唯一带 LAUNCHER 的组件是
`.LauncherAlias`，隐藏时它被禁用——因此仅靠别名方案会导致隐藏图标后
LSPosed 管理器里的"启动"按钮一并消失（旧版 bug）。

修复：在 `MainActivity` 上声明如下 intent-filter（`AndroidManifest.xml`）：

```xml
<intent-filter>
    <action android:name="android.intent.action.MAIN" />
    <category android:name="de.robv.android.xposed.category.MODULE_SETTINGS" />
    <category android:name="android.intent.category.INFO" />
</intent-filter>
```

- `MODULE_SETTINGS` 是 Xposed 规范中模块设置页的官方类别，LSPosed /
  太极等管理器都优先识别它，即使 LAUNCHER 别名被禁用也能解析到；
- `INFO` 是 `getLaunchIntentForPackage` 的第一优先回退类别，作为兼容兜底；
- 两个类别放同一个 filter 中，两路查询均可命中；
- `MainActivity` 保持 `exported="false"`：LSPosed 守护进程以 root
  身份启动组件，无需导出，不扩大攻击面；
- 桌面 Launcher 只认 `CATEGORY_LAUNCHER`，该 filter 不会让图标重新出现。

相关代码：`LauncherVisibility.kt`（`isHidden` / `setHidden`）。

## UI 交互

- 开关关闭 → 立即恢复桌面图标；
- 开关开启 → 弹出 `AlertDialog` 二次确认，明确告知隐藏后从 LSPosed
  管理器重新打开，确认后才执行隐藏；
- 开关下方的说明文字实时反映当前状态。

## 注意事项

- 若 LSPosed 管理器版本过旧无法从模块页面打开应用，可临时通过
  `adb shell am start -n io.github.imroxy2222.lsp_hongguoenhance/.MainActivity`
  恢复（或重装模块后关闭该开关）。
