# 设置页与配置

## 功能

模块自身 App（`MainActivity`，Compose + Material3）提供：

1. **LSPosed 框架服务状态**显示（已连接 / 未连接）；
2. **申请作用域**按钮 —— 调用 `XposedService.requestScope(["com.phoenix.read"])`，
   无需再去 LSPosed 管理器手动勾选；
3. **AI 接口配置**：
   - Base URL（默认 `https://api.openai.com/v1`）
   - API Key
   - 模型名（默认 `gpt-4o-mini`）
4. **采集参数**：
   - 首次采集评论数（默认 50，范围 10~200）
   - 单批加载条数（默认 30，范围 5~30）
   - 附加提示词（可选，追加到系统提示词末尾）
   - 取消思考（点击箭头展开按平台勾选携带的"关闭思考"字段，全部不勾即关闭，
     见 [AI词条总结](AI词条总结.md)）
   - AI 走模块进程（默认开启：AI 请求由模块进程发出，代理白名单只需放行模块；
     关闭则红果进程直连，见 [AI词条总结](AI词条总结.md)）
5. **评论词条日志**：
   - "查看日志"按钮 —— 打开 `LogViewerActivity`（按剧两级查看，见 [评论词条日志](评论词条日志.md)）
   - 保留天数（默认 30，0 = 不按天清理，范围 0~3650）
   - 总大小上限 MB（默认 100，0 = 不按大小清理，范围 0~4096）
   - 内部项 `log_token`：日志服务访问令牌，首次打开设置页自动生成，不在界面展示
6. **应用**：
   - **隐藏桌面图标** 开关（见 [隐藏桌面图标](隐藏桌面图标.md)）
7. **保存配置**。

## 界面说明

设置页 UI 采用 Material3 卡片分组 + 独立标题行，每个输入框标题右侧有
"?" 帮助徽标，点击弹出对话框说明用途，详见 [设置界面UI优化](设置界面UI优化.md)。

## 跨进程配置存储：remote preferences

设置页运行在**模块自身进程**，hook 代码运行在**红果短剧进程**，
二者内存隔离，普通 `SharedPreferences` 无法共享。

本模块使用 libxposed 框架提供的 **remote preferences**（`XposedServiceHelper`
注册监听 → `XposedService.getRemotePreferences(group)` 写入；宿主进程内
`XposedModule.getRemotePreferences(group)` 读取），由框架负责进程间同步。
相比传统 `XSharedPreferences`，不受 SELinux 与 world-readable 限制。

存储组名：`hge_settings`（常量 `ModuleConfig.PREFS_NAME`）。

| Key | 含义 | 默认值 |
|---|---|---|
| `base_url` | AI 接口基地址 | `https://api.openai.com/v1` |
| `api_key` | API 密钥 | 空 |
| `model` | 模型名 | `gpt-4o-mini` |
| `target_count` | 首次采集评论数 | 50 |
| `page_count` | 单批加载条数 | 30 |
| `extra_prompt` | 附加提示词 | 空 |
| `log_retention_days` | 日志保留天数（0=禁用） | 30 |
| `log_max_size_mb` | 日志总大小上限 MB（0=禁用） | 100 |
| `log_token` | 日志服务访问令牌（自动生成） | 空 |
| `disable_thinking` | AI 请求关闭思考模式 | true |
| `thinking_providers` | 携带"关闭思考"字段的平台 id，逗号分隔 | 全部（未配置时） |
| `ai_via_module` | AI 请求经进程桥走模块进程 | true |

保存成功后**重启红果短剧**生效（hook 进程在启动时初始化 `ModuleConfig`，
持有的是 `SharedPreferences` 实例，通常无需重启即可读到新值，但重启最稳妥）。

## 依赖

- `io.github.libxposed:service:102.0.0`（`implementation`）
- release 构建的 keep 规则已保留 `io.github.libxposed.service.**`
  （见 `app/src/main/keepRules/rules.keep`）。

## 注意事项

- 框架服务未连接时（如未装 LSPosed / 模块未启用），保存会被拒绝并提示；
- remote preferences 依赖 LSPosed 1.9.2+ / 内核支持 libxposed 服务协议的框架。
