# 安装与使用

## 前置要求

| 项 | 要求 |
|---|---|
| 设备 | Android 10+（API 29+，libxposed defaultClassLoader 特性要求） |
| 框架 | LSPosed（需支持 libxposed 100+ API 的新版内核） |
| 目标应用 | 红果短剧 `com.phoenix.read` |
| AI 服务 | 任一 OpenAI 兼容接口（DeepSeek / 通义 / Kimi / OpenAI 等） |

## 构建

```bash
cd HongGuoEnhance
./gradlew assembleDebug
# 产物: app/build/outputs/apk/debug/app-debug.apk
```

模块包名 `io.github.imroxy2222.lsp_hongguoenhance`，minSdk 29。

## 安装步骤

1. 安装 APK；
2. 打开模块 App：
   - 确认"LSPosed 框架服务：已连接"；
   - 点 **"申请红果短剧作用域"**（或在 LSPosed 管理器中手动勾选红果短剧）；
   - 填写 **Base URL / API Key / 模型名**，保存配置；
3. **强停红果短剧**后重新打开（模块在目标进程启动时注入）。

## 使用流程

1. 进入任意短剧的播放页（`ShortSeriesActivity`）；
2. 点击右侧栏 **分享按钮**（或选集弹窗底部的"分享"）——
   原分享面板被替换为 **"评论词条"** 页；
3. 页面自动开始采集剧评（默认 50 条、字数 >20 字）并调用 AI 总结，
   状态栏显示进度（`正在采集剧评 30/50...` → `正在调用 AI 分析 50 条剧评...`）；
4. 完成后展示词条为**横向条形图**（方案A）：每行 = 词条名（固定宽 96dp，
   AI 生成的超长词条自动跑马灯滚动，不压缩条形空间）+ 条形（长度∝次数占比，
   青色渐变圆角条，深灰轨道底）+ `×N`；按数量降序排列；
   状态栏显示统计：`总x条评论,参考y条,平均得分z`；
5. 觉得词条不够精确时，点 **"继续加载"** 追加下一批评论并重新总结；
6. 点 `✕` 关闭页面，继续正常看剧（原分享功能在其他页面不受影响）。

## 日志排查

模块日志统一使用 tag `HongGuoEnhance`，可用以下命令观察：

```bash
adb logcat -s HongGuoEnhance
```

关键日志：`hook share panel ok` / `page fetched: raw=10, filtered=8` /
`seriesId updated` / `AI tags: 18`。

## 行为边界与降级

| 场景 | 行为 |
|---|---|
| 非 ShortSeriesActivity 页面点分享 | 放行原分享面板 |
| 无法取到 seriesId | 放行原分享面板（不会白屏或闪退） |
| AI 未配置 / 请求失败 | 词条页显示错误信息 + 重试按钮 |
| 模块卸载/停用 | app 恢复原生行为，无残留 |

## 版本适配风险

模块依赖红果短剧若干**未混淆保留名**类（详见 [评论采集.md](评论采集.md)）
与一个混淆类 `ek2.o`（分享模型）。红果短剧大版本更新后如失效：

1. 用 jadx 重新导出，确认 `NsShareProxy.showShortSeriesSharePanel`、
   `CommentApiService.getCommentListRxJava`、模型字段名是否变化；
2. 相应调整 `SharePanelHook` / `CommentFetcher` 中的类名与字段名常量。
