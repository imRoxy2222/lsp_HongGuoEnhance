# 架构总览

## 模块定位

**HongGuoEnhance** 是一个基于 **libxposed API 102** 的 LSPosed 模块，作用域为
红果短剧（`com.phoenix.read`）。核心功能：

> 在短剧播放页（`ShortSeriesActivity`）点击分享按钮（view id `hq0`）时，
> 不再弹出原分享面板，而是弹出本模块的 **"评论词条"** 页面，
> 展示由 AI 从剧评中总结出的剧情评价词条（如 `杀伐果断 ×10`），
> 帮助用户快速判断该剧质量。

## 技术栈

| 组件 | 选型 |
|---|---|
| Xposed API | `io.github.libxposed:api:102.0.0`（compileOnly） |
| 模块↔框架服务 | `io.github.libxposed:service:102.0.0`（设置页写配置 / 申请作用域） |
| UI | 设置页 Compose (Material3)；词条页为宿主进程内纯代码 Dialog |
| 评论数据 | 复用红果短剧自身 RPC（反射调用，签名/公共参数由 app 处理） |
| AI 请求 | `HttpURLConnection` + `org.json`，OpenAI 兼容 `/chat/completions` |

## 整体链路

```
[模块设置页进程]                     [红果短剧进程（hook 注入）]
MainActivity (Compose)
  │ XposedServiceHelper
  │   .getRemotePreferences("hge_settings") ──写入──┐
  │                                                │ libxposed 框架同步
  └── requestScope(申请作用域)                      ▼
                                        HookEntry (XposedModule)
                                          │ onPackageLoaded
                                          ▼
                                     SharePanelHook
                                       ├─ hook NsShareProxy.showShortSeriesSharePanel
                                       │    → 拦截，弹 TagDialog（替换分享面板）
                                       ├─ hook ek2.o 构造 / SaasVideoData.getSeriesId
                                       │    → 采集当前 seriesId
                                       └─ hook CSSPlayletCommentListActivity.onCreate
                                            → 兜底采集 seriesId
                                       
                                     Pipeline（流程编排）
                                       ├─ CommentFetcher：反射调 CommentApiService
                                       │    .getCommentListRxJava(request) 分页拉剧评
                                       └─ AiClient：POST {baseURL}/chat/completions
                                            → 解析词条 → 按 count 降序
```

## libxposed 102 API 要点

本模块使用 libxposed **102 新式 API**（与旧版 100 的 `@Hooker` 注解风格不同）：

```kotlin
// 入口：无参构造，框架通过 attachFramework 注入
class HookEntry : XposedModule() {
    override fun onPackageLoaded(param: PackageLoadedParam) { ... }
}

// hook：链式 HookBuilder + 函数式 Hooker（intercept/Chain/proceed）
xposed.hook(method).intercept { chain ->
    // ... 拦截逻辑
    chain.proceed()        // 调用原实现；不调用即替换
}

// 配置共享：设置页进程与宿主进程读写同一份
xposed.getRemotePreferences("hge_settings")   // SharedPreferences 语义
```
