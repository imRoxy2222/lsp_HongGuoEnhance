# 评分雷达图（六维评分）

## 功能说明

评论词条弹窗现在包含两个可切换的页面：

1. **评论词条**（原有）：词条胶囊 + 横向条形图（前 10 名）；
2. **六维评分**（新增）：六边形雷达图，直观展示剧集各维度的口碑分布。

弹窗内容区支持**左右滑动循环切换**两页——无界滑动，可以一直左滑、也可以一直右滑，
每次滑动翻一页，页序循环（词条 → 雷达 → 词条 → …）。
弹窗底部有两枚圆点指示器 + 当前页名（"评论词条" / "六维评分"）。

设置页新增「**默认显示六维雷达图**」开关（展示设置分组，默认关闭）：
控制弹窗打开时默认停留在哪一页；仅影响默认页，滑动切换始终可用。

|---|---|---|

| 音乐 | bgm / 配乐 / 插曲 / 主题曲 / 好听 | 难听 / 吵死 |
| 爽感 | 爽 / 解气 / 打脸 / 逆袭 / 过瘾 / 上头 | 憋屈 / 气死 / 膈应 / 窝囊 |
| 期待 | 期待 / 追更 / 催更 / 等更新 / 第二季 / 蹲后续 | 弃了 / 弃剧 / 不想看了 |
| 画面 | 画面 / 颜值 / 好看 / 特效 / 妆造 / 质感 | 太土 / 丑 / 廉价 / 辣眼睛 |

> 第六角选了**节奏**：短剧观众高频提及"紧凑/拖沓/注水"，与剧情维度区分度高。

## 评分来源：AI 输出优先，本地关键词回退

### 主通道：AI 六维评分（默认）

系统提示词要求 AI 在输出词条 JSON 的同时附带六维评分：

```json
{"tags":[{"tag":"词条","count":10,"negative":false}],
 "dims":{"剧情":8.5,"音乐":7,"爽感":8,"期待":7.5,"画面":8,"节奏":8.5}}
```

- AI 未涉及的维度提示其给 5 分左右的中间分，不要凭空猜测；
- 响应只多约 100 字节，**不增加请求次数**；
- 全链路透传：宿主直连（`AiClient`）与进程桥（`AiBridgeProvider` → `AiBridge`）均解析并传递 dims；
- 任一维度缺失或类型不对 → 整体视为未返回，走本地回退；
- 落库：`ai_log` 新增 `dims` 列（DB v5 迁移），恢复会话后雷达图直接复用，不再重算。

**增量合并**（"继续加载"）：AI 的 dims 只反映本次发送的批次，按各自覆盖的评论数加权合并：
`merged = (旧值 × 旧评论数 + 新值 × 新评论数) / 总评论数`。

### 回退通道：本地关键词分析

AI 未返回 dims（旧模型不遵循格式、旧记录恢复等场景）时，
用 `hook/DimensionAnalyzer.kt` 对已采集评论做关键词正/负倾向投票：

```
dim = baseline + 2.5 × (正票 − 负票) / max(提及条数, 8)     结果截断到 [1, 10]
baseline = 总采集评论平均分（scoreSum / rawCount，10 分制）
```

- 净倾向占比 ∈ [-1, 1]，按提及条数收敛（**最少按 8 条计**）——单条评论提及不会大幅拉动分值；
- **从未被提及的维度直接取基线**（整体平均分），雷达图呈"平边"。

弹窗雷达页底部说明行会标明当前来源："AI 六维评分" 或 "关键词推算"。

## 数据流

```
AI 响应 ──parseResult──> AiResult.dims ─┬─ 宿主直连：直接返回
                                        └─ 进程桥：EXTRA_DIMS 透传 → AiBridge 解析
Pipeline.runAi
  ├─ 全量模式：cache.dims = AI dims（null 则本地回退）
  ├─ 增量模式：旧值×旧评论数 与 新值×新评论数 加权合并
  └─ 落库 ai_log.dims（JSON）+ 恢复会话时读回
TagDialog.onTags ──> RadarChartView.setData（AI dims 优先，null 则本地分析）
```

## 实现位置

| 文件 | 职责 |
|---|---|
| `hook/AiClient.kt` | 提示词要求输出 dims；`parseResult` 解析词条 + 六维评分 |
| `hook/AiBridgeProvider.kt` / `hook/AiBridge.kt` | 进程桥应答透传/解析 `EXTRA_DIMS` |
| `hook/Pipeline.kt` | dims 缓存、增量加权合并、落库、恢复会话 |
| `hook/LogStore.kt` | `ai_log.dims` 列（DB v5）与回读 |
| `hook/DimensionAnalyzer.kt` | 回退通道：六维关键词投票评分 |
| `hook/RadarChartView.kt` | 自绘六边形雷达图（网格/轴线/数据多边形/顶点分值/维度标签/展开动画/空态） |
| `hook/TwoPageCarousel.kt` | 双页无限轮播容器：无界虚拟页位置 mod 2 映射子页；水平拖动跟手，位移过半（40%）或 fling 提交翻页；垂直滚动（词条页 ScrollView）不拦截 |
| `hook/TagDialog.kt` | 弹窗集成：轮播 + 雷达页 + 圆点指示器 + 默认页配置 + 评分来源选择 |
| `hook/ModuleConfig.kt` | `radar_default_view`（默认 false） |

## 已知局限

- AI 六维评分质量取决于模型对提示词的遵循度；不遵循时自动回退本地关键词分析；
- 本地关键词匹配为**子串包含**，存在少量误伤/漏检（如"好看"既可形容画面也可形容剧情），
  属于启发式展示，不代表精确评分；
- 雷达图依赖已采集的评论文本（AI 参考评论），首次采集完成前显示"暂无评论数据"；
- 本地关键词集合目前内置，暂不支持自定义（可按需开放配置）。
