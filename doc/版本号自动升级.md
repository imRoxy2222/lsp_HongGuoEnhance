# 版本号自动升级

## 功能说明

APK 的 `versionCode` 与 `versionName` 不再是固定的静态值, 而是在每次打包时自动取 **当前打包分支的 commit 次数**。

以 master 分支 11 次提交为例, 打包产物版本为 `versionCode = 11`, `versionName = "11"`。此后每新增一次 commit 并重新打包, 版本号自动 +1, 无需手动修改 `build.gradle.kts`。

## 实现位置

`app/build.gradle.kts`

```kotlin
import org.gradle.api.provider.ValueSource
import org.gradle.api.provider.ValueSourceParameters

// 获取当前分支 commit 次数作为版本号来源 (兼容 Configuration Cache)
// 输出非整数或执行异常时返回 null, 由 getOrElse 回退为 1
abstract class GitCommitCountSource : ValueSource<Int, GitCommitCountSource.Params> {
    interface Params : ValueSourceParameters {
        val projectDir: Property<String>
    }

    override fun obtain(): Int? {
        return try {
            val process = ProcessBuilder("git", "rev-list", "--count", "HEAD")
                .directory(File(parameters.projectDir.get()))
                .redirectErrorStream(true)
                .start()
            val output = process.inputStream.bufferedReader().readText().trim()
            process.waitFor()
            output.toIntOrNull()
        } catch (e: Exception) {
            null
        }
    }
}

val commitCount = providers.of(GitCommitCountSource::class) {
    parameters.projectDir.set(rootDir.absolutePath)
}.getOrElse(1)
```

在 `defaultConfig` 中:

```kotlin
versionCode = commitCount
versionName = commitCount.toString()
```

## 设计要点

- **git 命令**: `git rev-list --count HEAD`, 统计的是当前检出分支的提交总数, 与打包时所在分支一致。
- **Configuration Cache 兼容**: 本项目启用了 `org.gradle.configuration-cache=true`。配置阶段直接执行外部进程会违反 Configuration Cache 规则导致构建失败, 因此必须使用 Gradle 官方的 `ValueSource` API。ValueSource 的值在配置缓存加载时会重新执行校验, 若 commit 次数变化会自动触发重新配置, 保证每次打包拿到的是最新 commit 数。
- **容错**: git 命令执行失败 (如未安装 git、非 git 仓库) 或输出无法解析为整数时, 由 `getOrElse(1)` 回退为版本号 1, 不中断打包。
- **工作目录**: 通过参数传入项目根目录 (`rootDir`), 在任意子目录执行 gradle 任务结果一致。

## 验证方式

```bash
git rev-list --count HEAD   # 查看当前 commit 次数
./gradlew :app:assembleDebug
```

已验证 (2026-10-27): master 分支 commit 次数为 11, 打包后合并清单中为 `versionCode="11"` `versionName="11"`, 构建通过且 Configuration Cache 正常存储 (`Configuration cache entry stored`)。
