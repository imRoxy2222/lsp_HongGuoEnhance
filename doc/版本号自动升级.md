# 版本号自动升级（tag 驱动）

## 功能说明

APK 的 `versionCode` 与 `versionName` 在打包时自动取 **最近的 `v*` tag 的数字**
（如 `v14` → `versionCode = 14`, `versionName = "14"`）。

- CI 发布：HEAD 即所打 tag，版本号恒等于 tag 数字；
- 本地开发：取祖先提交上最近的 `v*` tag；
- 仓库没有任何可达 `v*` tag 时回退为 1。

版本号随 tag 序列 **v1 → v2 → v3 … 递增**，与 commit 次数无关。
发布流程（`release.yml`）会硬校验 tag 递增：**打 `vN` 必须已存在 `v(N-1)`**
（`v1` 除外），跳号直接失败、不打包，详见 [GitHub自动发布](GitHub自动发布.md)。

## 实现位置

`app/build.gradle.kts`

```kotlin
// 版本号来源: 最近的 v* tag 的数字 (如 v14 → 14), 兼容 Configuration Cache。
abstract class GitTagVersionSource : ValueSource<Int, GitTagVersionSource.Params> {
    interface Params : ValueSourceParameters {
        val projectDir: Property<String>
    }

    override fun obtain(): Int? {
        return try {
            val process = ProcessBuilder(
                "git", "describe", "--tags", "--match", "v*", "--abbrev=0"
            )
                .directory(File(parameters.projectDir.get()))
                .redirectErrorStream(true)
                .start()
            val output = process.inputStream.bufferedReader().readText().trim()
            process.waitFor()
            output.removePrefix("v").toIntOrNull()?.takeIf { process.exitValue() == 0 }
        } catch (e: Exception) {
            null
        }
    }
}

val appVersion = providers.of(GitTagVersionSource::class) {
    parameters.projectDir.set(rootDir.absolutePath)
}.getOrElse(1)
```

在 `defaultConfig` 与 `generateModuleProp` 中使用：

```kotlin
versionCode = appVersion
versionName = appVersion.toString()
```

## 设计要点

- **git 命令**：`git describe --tags --match v* --abbrev=0`，返回当前提交可达的
  最近的 `v*` tag 名；剥离 `v` 前缀后解析为整数。
- **Configuration Cache 兼容**：本项目启用了 Configuration Cache，配置阶段执行
  外部进程必须走 `ValueSource` API；tag 变化会自动触发重新配置。
- **容错**：无 tag、git 不可用、输出无法解析为整数时 `getOrElse(1)` 回退为 1，
  不中断打包。
- **工作目录**：通过参数传入项目根目录（`rootDir`），任意子目录执行结果一致。

## 验证方式

```bash
git describe --tags --match "v*" --abbrev=0   # 查看最近的 v* tag
./gradlew :app:assembleDebug
grep versionCode app/build/generated/moduleProp/META-INF/xposed/module.prop
```

已验证（2026-10-28）：最近 tag 为 `v13`，打包后 module.prop 为
`version=13` / `versionCode=13`，构建通过。
