# 桌面图标更换（拟人化西红柿）

## 功能说明

将 LSPosed 模块 HongGuoEnhance 的桌面启动图标更换为定制设计图：白底 + 只有嘴和手的拟人化西红柿 + 卡通便便 + 红色禁止符号（圆圈加斜杠）包裹全图，整体含义为"我不吃屎"。

图标原图为 AI 生成的"卡通贴纸风"方案（用户从 3 张备选中挑选），源图存放于 `icon_drafts/Kawaii_cartoon_style_app_icon__2026-10-28T07-29-59.png`。

## 实现方式

### 1. 图标资源生成

使用 Python + Pillow 脚本 `icon_drafts/gen_icons.py` 从 1024x1024 源图批量生成以下资源：

| 资源 | 密度/尺寸 | 说明 |
| --- | --- | --- |
| `mipmap-*/ic_launcher.webp` | 48/72/96/144/192 px | 普通启动图标，整图直接缩放 |
| `mipmap-*/ic_launcher_round.webp` | 48/72/96/144/192 px | 圆形图标：白色圆形底 + 内接正方形放置整图，保证禁止圈完整不被裁切 |
| `mipmap-*/ic_launcher_foreground.webp` | 108/162/216/324/432 px | 自适应图标前景：108dp 画布，内容缩放至 0.64 倍（安全区 66/108 留余量），避免启动器蒙版裁掉禁止圈 |

### 2. 自适应图标配置

`res/mipmap-anydpi/ic_launcher.xml` 与 `ic_launcher_round.xml` 修改为：

```xml
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@color/white" />
    <foreground android:drawable="@mipmap/ic_launcher_foreground" />
</adaptive-icon>
```

- 背景改为纯白（`@color/white`，已有颜色资源）
- 前景改为位图资源（原图标为绿色矢量 drawable）

### 3. 清理旧资源

删除不再被引用的 `drawable/ic_launcher_background.xml` 和 `drawable/ic_launcher_foreground.xml`。

### 4. monochrome 层说明

原自适应图标包含 `<monochrome>` 主题图标层，引用的是彩色位图后效果会很差（剪影不可辨识），故本次已移除该层；如需支持 Android 13 主题图标，可后续补充单色矢量版前景。

## 验证

- `gradlew :app:assembleDebug` 编译通过
- APK 内确认包含 `mipmap-anydpi-v21` 两个 adaptive-icon XML 及全部密度的三个 webp 图标资源

## 相关文件

- 源图与生成脚本：`icon_drafts/`（含 3 张备选图，1 号扁平矢量风、2 号卡通贴纸风[已选用]、3 号极简几何风）
- 图标资源：`app/src/main/res/mipmap-*`
- 自适应图标配置：`app/src/main/res/mipmap-anydpi/ic_launcher.xml`、`ic_launcher_round.xml`
